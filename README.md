# cs-image-system-starter-tree (archived)

This repository is retired: to try cs-image-system, follow [the quickstart](https://github.com/infrastructurebuilder/cs-image-system-3/blob/develop/docs/QUICKSTART.md), a first dry run on your own machine in about fifteen minutes.

To start a configuration repository, use one of the five template repositories, each regenerated with every final release: [standard-aws](https://github.com/infrastructurebuilder/cs-image-system-starter-standard-aws), [standard-gce](https://github.com/infrastructurebuilder/cs-image-system-starter-standard-gce), [complete](https://github.com/infrastructurebuilder/cs-image-system-starter-complete), [standard-aws-posix](https://github.com/infrastructurebuilder/cs-image-system-starter-standard-aws-posix) and [standard-docker](https://github.com/infrastructurebuilder/cs-image-system-starter-standard-docker).

The guide to setting up a configuration repository's CI now travels with every tree, as its `CI_SETUP.md`.
